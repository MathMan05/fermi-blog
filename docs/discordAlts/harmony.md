# What's the deal with Harmony?
There is a lot to say about Harmony, lets start off with some of the good things about it.

Good things about Harmony:

- Bridge bot support is excellent
	* It's pretty good with the ability to set per message pfps/usernames allowing for one bot without webhook perms to be a rather effective bridge.
- Fully FOSS
- The client is meant for discord like communication
- The Bot libraries are decent
	* though this just means that you can use the discord libs in this case
- Discord API compatible

## Final Thoughts
While I have much less to say about Harmony than Revolt/Stoat it's due to the fact that it mostly works as intended, and does not have many of the organizational issues that they have.
